# 👥 Employees Attrition Analysis

An interactive **Power BI dashboard** designed to analyze employee attrition and identify the key factors contributing to employee turnover.

## 🎯 Project Overview

This project analyzes employee data to understand **attrition patterns across departments, job roles, salary bands, employee tenure, and promotion history**.

The dashboard helps organizations identify high-risk employee segments and support data-driven workforce decisions.

## 🛠️ Tools & Technologies

* **Power BI**
* **Power Query**
* **DAX**
* **Data Modeling**
* **Data Visualization**
* **Excel**

## 📊 Dashboard Analysis

The dashboard provides insights into:

* 👥 Employee Attrition
* 🏢 Department Performance
* 💼 Job Role Analysis
* 💰 Salary Band Analysis
* 📅 Employee Tenure
* 📈 Promotion History
* 🚗 Commute Distance
* ⭐ Employee Engagement
* 📊 Attrition Rate

## 🔄 Data Preparation

The data was cleaned and transformed using **Power Query**, including:

* Removing duplicate records.
* Handling missing values.
* Correcting data types.
* Creating calculated columns.
* Preparing the dataset for analysis.

## 📐 DAX & Data Modeling

A structured data model was created to support interactive analysis.

DAX measures and calculated columns were developed for metrics such as:

* Total Employees
* Employees Who Left
* Active Employees
* Attrition Rate
* Average Tenure
* Average Salary
* Years Since Last Promotion
* Average Engagement Score

## 💡 Key Insights

The analysis helps identify:

* Job roles with the highest attrition.
* Departments with higher employee turnover.
* Salary bands associated with higher attrition.
* Employees with long periods without promotion.
* Relationship between commute distance and attrition.
* Impact of employee engagement on turnover.
* Average employee tenure at the time of exit.

## 🚀 Business Recommendations

Based on the analysis, organizations can:

* Focus retention strategies on high-risk job roles.
* Review compensation for high-attrition salary bands.
* Improve career development and promotion opportunities.
* Monitor employee engagement.
* Consider commute-related factors when designing retention strategies.
* Develop targeted retention programs for high-risk employee segments.
